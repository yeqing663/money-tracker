# 随手记 · 极简手机记账

单文件手机记账 App，无后端、无联网。数据只存在你手机浏览器本地。

## 在线使用

https://yeqing663.github.io/money-tracker/

iPhone：Safari 打开 → 分享 → 添加到主屏幕（之后固定从图标打开，别和 Safari 混用）。

## 功能

- 支出 / 收入，9 类支出 + 5 类收入
- 本月支出 / 收入 / 结余实时汇总
- 导出 CSV / 复制 CSV / 导入 CSV（与电脑端 记账数据.csv 格式一致）
- 删除单条记录
- 数据存 localStorage，不上传任何服务器

## 备份

每周点「导出 CSV」或「复制 CSV」。复制的内容可直接粘贴给 AI，合并进电脑端账本并重建报表。

## 技术

纯 HTML + CSS + JS，单文件，无依赖、无构建、无 CDN。
